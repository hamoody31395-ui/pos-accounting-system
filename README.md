## ✨ المميزات

### 🛒 نقطة البيع (POS)
- واجهة بيع سريعة وسهلة الاستخدام
- بحث المنتجات بالاسم أو الباركود
- تصنيف المنتجات لتصفية سريعة
- سلة مشتريات مع تعديل الكميات
- دعم 3 طرق دفع (نقدي، بطاقة، شبكة)
- حساب الضريبة والخصومات تلقائياً
- حساب الباقي تلقائياً
- طباعة إيصال البيع

### 👥 إدارة المستخدمين
- 3 مستويات صلاحيات (مدير عام، كاشير، محاسب)
- شاشة إعداد أولي عند أول استخدام
- تسجيل دخول وتسجيل مشترك جديد
- تفعيل/تعطيل المستخدمين

### 📦 إدارة المنتجات والمخزون
- إضافة وتعديل وحذف المنتجات
- تصنيف المنتجات بألوان مميزة
- تنبيهات المخزون المنخفض 🔴
- دعم الباركود
- أسعار التكلفة والبيع

### 💵 إدارة المصروفات
- تسجيل المصروفات اليومية
- تصنيف المصروفات (إيجار، كهرباء، صيانة...)
- تتبع المصروفات بالمستخدم والتاريخ

### 📊 إغلاق اليومية
- تسوية الدرج النقدي
- ملخص المبيعات والمصروفات
- حساب صافي الربح
- سجل تاريخي لإغلاقات اليومية

### 📈 التقارير
- تقرير المبيعات اليومية
- تقرير المبيعات الشهرية
- أفضل المنتجات مبيعاً
- تقرير المخزون
- تقرير الأرباح

## 🚀 التثبيت والتشغيل

### المتطلبات
- Node.js 18+
- Bun أو npm

### خطوات التثبيت

```bash
# 1. استنساخ المشروع
git clone https://github.com/hamoody31395-ui/pos-accounting-system.git
cd pos-accounting-system

# 2. تثبيت الحزم
bun install
# أو
npm install

# 3. إعداد قاعدة البيانات
bun run db:push

# 4. تعبئة البيانات الأساسية
# (سيتم تلقائياً عند أول تشغيل)

# 5. تشغيل المشروع
bun run dev
```

### بعد التشغيل
1. افتح المتصفح على `http://localhost:3000`
2. ستظهر شاشة **إعداد النظام** (لأنها أول مرة)
3. أنشئ حساب المدير بالبيانات المطلوبة
4. ابدأ الاستخدام!

## 📁 هيكل المشروع

```
src/
├── app/
│   ├── api/              # واجهات API
│   │   ├── auth/         # المصادقة (تسجيل دخول، تسجيل)
│   │   ├── products/     # المنتجات
│   │   ├── categories/   # التصنيفات
│   │   ├── sales/        # المبيعات
│   │   ├── expenses/     # المصروفات
│   │   ├── users/        # المستخدمين
│   │   ├── day-close/    # إغلاق اليومية
│   │   ├── reports/      # التقارير
│   │   ├── settings/     # الإعدادات
│   │   └── seed/         # بيانات تجريبية
│   ├── layout.tsx        # التخطيط الرئيسي (RTL)
│   ├── globals.css       # الأنماط العامة
│   └── page.tsx          # الصفحة الرئيسية
├── components/
│   └── ui/               # مكونات shadcn/ui
├── hooks/                # React Hooks
├── lib/                  # وظائف مساعدة
├── store/                # Zustand Store
└── types/                # أنواع TypeScript
```
